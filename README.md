# 🚗 Análise de Veículos — Dashboard Interativo
Aplicação desenvolvida em Python + Streamlit para explorar dados de veículos usados a partir do arquivo vehicles.csv.
O dashboard permite visualizar distribuições, relações entre variáveis e aplicar filtros de forma simples e intuitiva.
